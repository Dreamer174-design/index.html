Import from M-Pesa

Open your Messages app, select several M-Pesa confirmation texts, copy, and paste them here. Only "sent to", "paid to", and "withdrawn" messages are picked up as expenses — incoming money is ignored. This is a best-effort reading, so double-check the review screen before importing.
